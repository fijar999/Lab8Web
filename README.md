# Praktikum PHP Modul 8 – Database

## 1. Tujuan
Praktikum ini bertujuan untuk mempelajari cara menghubungkan PHP dengan database MySQL serta melakukan pengelolaan data barang melalui operasi CRUD (Create, Read, Update, Delete).

## 2. Perangkat yang Digunakan
- Visual Studio Code
- XAMPP (Apache dan MySQL)
- PHP
- MySQL / phpMyAdmin
- Browser

## 3. Cara Menjalankan Program
1. Simpan folder project di dalam direktori `C:\xampp\htdocs`.
2. Jalankan Apache dan MySQL melalui XAMPP.
3. Pastikan database `latihan1` sudah dibuat melalui phpMyAdmin.
4. Buka browser dan akses `http://localhost/lab8_php_database/`.
5. Program siap digunakan untuk mengelola data barang.
